## Cómo Ejecutar Localmente

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/Ignagatti/Portfolio.git
   cd Portfolio
   ```

2. Abrir con cualquier servidor local:
   - Con Python:
     ```bash
     python -m http.server 3000
     ```
   - O con la extensión Live Server de VS Code.
